# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, the page involved, and steps to reproduce it. You will get a response as soon as the maintainer is able.

## What this site is

A static website with no accounts, no database and no stored visitor data. It sets no cookies; the only thing it stores in your browser is your light or dark theme choice.
