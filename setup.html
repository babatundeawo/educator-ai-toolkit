Set up your Project

One Project, done once. It then generates both lesson notes and exams, because a single Master Instruction reads every request and figures out which one you're asking for. Follow the steps below in order.

Look for the app by Anthropic (white background, orange logo). Open it and tap Sign Up, fastest is "Continue with Google," or use your email and confirm the verification link Claude sends you.

Don't share your Claude login with anyone, treat it like your email password.

2

Create one Project

This single Project does everything, for every subject and class

You only need one Project for your whole school. Name it something like School Document Generator. It generates lesson notes, exams, marking guides, and revision files, for any subject or class, once it's set up.

Phone app
  1. Open the menu (☰) → Projects
  2. Tap New Project
  3. Name it, tap Create
Computer, claude.ai
  1. Projects in the sidebar
  2. Click New Project
  3. Name it, click Create

Turn on two Project capabilities (usually under the Project's settings or a tools/capabilities icon near the message box): Web search and Analysis / code execution. Lesson notes now embed real diagrams, graphs, charts, and maps directly in the document, generated or fetched using these two capabilities, instead of just telling you what to go and find yourself.

3

Fill in your details & copy the Master Instructions

Type your details below, the text updates as you go

Fill in the four fields below. The instructions underneath update automatically, so you can check exactly what you're about to paste. Anything still highlighted in gold hasn't been filled in yet.

Once every field looks right above, copy the text and paste it into the Project's Custom Instructions / Project Instructions field. This is the only text field you'll maintain, everything else below is just uploaded files.

4

Upload the knowledge files

The Scheme of Work, the two reference files, plus anything else you have

Open Project Knowledge in your Project (or "Add content") and upload the Scheme of Work file(s) for what you teach, plus the two reference files below.

Pick your class below, tick the subject(s) you teach, and download only those. Teaching several subjects or classes? Select and download as many as you need, upload them all together.
