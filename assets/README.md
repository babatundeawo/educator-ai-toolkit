# assets

Shared files used by every page: `style.css` (design tokens and components), `script.js` (theme, search, step wizard, scheme picker), `pwa.js` (install prompt, update bar, offline notice, service worker registration), `theme-init.js` (applies the saved theme before first paint), `master-editor.js` (the Master Instructions editor on the setup page), the logo, favicon, app icons and social preview image. `fonts/` is filled in during the build (see `../scripts/fetch_fonts.sh`) and is not committed.
