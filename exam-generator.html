Make sure your Project is set up

Not set up yet? Head to Set up your Project first, it only takes about 15 minutes and covers this tool and the Lesson Note Generator together.

2

Ask for an exam or revision file

State the Term, Subject and Class, no Week number

Always state the Term, Subject, and Class, and make clear whether you want an exam or a revision file. Leaving out a Week number is what tells the Master this isn't a Lesson Note request.

Exam requests
  • "Generate First Term Examination for Physics SS2"
  • "Create 2nd term exam, Basic Science, JSS1"
  • "Third term, Mathematics, JSS3"
Revision file requests
  • "Generate a revision file for Second Term, Physics, SS2"
  • "Create revision notes for First Term, Basic Science, JSS1"
  • "Third term revision file for Chemistry SS1"

Missing or unclear details, or a request that could be read as either a lesson note or an exam? Claude asks you to confirm rather than guessing.

Where content comes from

For every topic, in this order: an uploaded textbook, then an uploaded e-note, then Claude's own online research to fill any gap. The Scheme of Work always decides which topics are in scope, uploaded materials are never the source of the topic list itself.

Subject name matching

Requests don't have to match the Scheme of Work's exact wording. Common aliases are recognised automatically, e.g. "Agric" for "Agricultural Science," "PHE" for "Physical and Health Education," "CRS" for "Christian Religious Studies," "Civic Education" for "Citizenship and Heritage Studies," "Computer Studies"/"ICT" for "Digital Technologies," and more. A subject with no scheme entry at all (e.g. Yoruba, Arabic) falls back to an uploaded e-note or online research instead.

Non-teaching weeks

Weeks labelled "Midterm Examination," "Midterm Break," "Revision & Exams," "Closing," or similar are automatically excluded from the topic list used to build questions, no need to flag this or ask.

Enrichment vs. mismatch

Enrichment, not flagged

An uploaded e-note covers extra sub-topics within the same broad area the scheme names (e.g. scheme says "Sequences and Series," e-note also covers "Geometric Sequences"). Included automatically, no flag.

Mismatch, flagged

An uploaded e-note is about an unrelated topic entirely. Claude still follows the scheme's topic and says so in its reply, noting the content was built from a textbook or research instead.

Within any single term, questions spread evenly across every topic in that term's Scheme of Work, plus any enrichment sub-topics from an uploaded e-note. For English Studies/English Language, each of the term's parallel strands counts as its own topic for this spread.

Section A, Objective (30 marks)

  • 30 questions, 1 mark each, 4 options lettered A to D, question and options on one line.
  • Answer key is randomly and evenly distributed, never dominated by one letter.

Section B, Theory (40 marks)

1st / 2nd term

5 questions, answer any 4, 10 marks each.

3rd term

6 questions (1+1+4), answer any 5, 8 marks each.

Revision file, in detail

Always 100% from the single requested term's Scheme of Work topics, even a "Third Term revision file" never mixes in 1st/2nd term content. One Word document: Summary Notes (every topic in that term, plus any e-note enrichment) followed by Practice Questions (theory-style, spread evenly across topics, each with its full answer directly underneath, since this is a self-study document, not a graded one).

Full workflow

  1. Parse Term, Subject, Class, ask if anything is missing or if lesson-note-vs-exam is ambiguous.
  2. Match the subject against the Scheme of Work (handling aliases), locate its topic list for the relevant term(s), and exclude non-teaching weeks.
  3. Check for a matching e-note/textbook, and classify any difference as enrichment or mismatch.
  4. Apply the term-based composition ratio, spreading questions across all scheme topics.
  5. Build the Question Paper and the Marking Guide (or the Summary Notes + Practice Questions for a revision file), sourcing content textbook → e-note → online research.
  6. Save and present the file(s), noting any mismatch flagged in step 3.

Quick reference

  • Not happy with a result? Reply in the same chat, e.g. "Redo Section A" or "Make theory harder."
  • Want a fresh version? Run the same request again, questions vary each time.
  • Adding more materials? Upload extra e-notes or textbooks to the Project any time, they enrich the Scheme of Work, they don't replace it.
